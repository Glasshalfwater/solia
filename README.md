# solia
### A compact tamagotchi in a rectangular form factor:

This originally started off as an idea for a birthday gift, however I realized that the timeline in which I had hoped to accomplish it was quite unrealistic. It also served as a fun way to learn KiCad (my previous projects were designed in EasyEDA Pro). The actual tamagotchi guided project took maybe 3-4 days to finish, but I wanted to make it, frankly, cooler. I decided to add a full-color TFT display, Kailh Choc keys for a more satisfying user experience, and a LiPO battery (of course along with temperature monitoring, fuse, etc.) for improved battery life. Soooo, it's been about a month and a half since I started this, said person's birthday passed a month ago, but hopefully it will be finally built soon. Another reason why I wanted to build something more complex than a basic tamagotchi (other than making it more interesting as a gift) was so it would be more fun to update later down the line. I could create "DLCs" or expansions to serve as further iterations or updates. (I had wanted to make a full color tamagotchi, so I was thinking of continuously adding new creatures with better graphics.)

### Setup Instructions:
Once your PCBs, case, and components arrive (list of used components), attach the XIAO via USB-C data cable to a computer capable of flashing firmware. There are multiple ways of doing so, but given that the firmware is already a .ino file, one could simply install Arduino IDE and use the built in flashing tool (just google Arduino IDE install and docs). Afterwards, assemble the PCB components, where you will likely need a hot plate for the XIAO board. Or, if you didn't screw up like me, I highly recommend editing the PCB files to include holes underneat the XIAO battery pads, so you don't have to only use solder paste and hope (if you're editing the PCB, I also recommend swapping the placement of the buzzer and the XIAO, as I didn't realize that the pins from the buzzer would hit the SD card slot attached to the screen). There is a very specific order to which the components need not to be assembled, but essentially just solder the XIAO first and confirm that nothing is shorted (multimeter, etc.), then the buzzer and temperature sensor, then the keys, and lastly the screen (as long as the XIAO is first and the screen is left to last it should be fine). Afterwards, solder the temperature fuse in between one of the battery wires (I chose positive) and the female JST connector on the board and tape the fuse onto the battery's back (adjust the postition so it slots into the hole in the case). Once you've assembled everything onto the board, place foam around the bottom of the case except for in the cutout for the fuse, and nestle the battery in. Plug the battery into the board, place everything in and seal the top of the case, and you should be good to go!
